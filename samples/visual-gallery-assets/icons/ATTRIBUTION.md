Files are written **verbatim from upstream**, so `sha256(<file>.svg)` here equals
`sha256(<file>.svg)` in the repository above at that commit. That equality is what
makes `icons.lock.json` a checkable claim rather than bookkeeping, and it is
verified by `scripts/vendor_native_icons.py --check`.

The icons are used as **labels for a chart type**, not as depictions of what any
particular Power BI build renders. No Microsoft icon silhouette, card geometry or
pixel styling has been reproduced here.

## What each file is for

One file per native PBIR `visualType`, named after the type. Three tiers, because
an honest icon does not exist for every visual and a silently wrong one is worse
than an admitted gap:

| Tier | Count | Meaning |
|---|---|---|
| `icon` | 30 | A single glyph represents this visual type honestly. |
| `schematic` | 10 | No glyph is honest, so the gallery draws a labelled CSS diagram instead. |
| `collision` | 18 | No distinct glyph exists, so a sibling type shares this icon. The reason is recorded per type. |

### `schematic` — 10 type(s)

- **`aiNarratives`** → `tabler:typography` — Excluded type, but the same shape as narrative. Drawn identically.
- **`hundredPercentStackedAreaChart`** → `tabler:chart-area` — 100% stacking normalises every column to the same height, which is the one thing the chart-area outline cannot convey. Drawn as a normalised stack.
- **`hundredPercentStackedBarChart`** → `tabler:chart-bar` — Same reason as the column variant. Drawn as a normalised stack.
- **`hundredPercentStackedColumnChart`** → `tabler:chart-column` — Same reason as the area variant: normalisation removes the height cue the column glyph relies on. Drawn as a normalised stack.
- **`keyDriversVisual`** → `tabler:trending-up` — Key influencers is a list of drivers each labelled increasing or decreasing, which no glyph encodes. Drawn as signed driver rows.
- **`kpi`** → `tabler:target-arrow` — A KPI is a value plus a status indicator plus a target, which reads as a single arrow. Drawn as a value tile with a state and a goal.
- **`lineClusteredColumnComboChart`** → `tabler:chart-line` — A combo is two marks on two axes at once, which no single glyph represents. Drawn as columns with an overlaid line.
- **`lineStackedColumnComboChart`** → `tabler:chart-line` — As above, with a stacked column mark instead of a clustered one.
- **`narrative`** → `tabler:typography` — Narrative output is prose with a headline and insight lines. Drawn as a narrative card.
- **`ribbonChart`** → `tabler:chart-arrows` — A ribbon ranks categories and carries the second-highest value as a trailing band, which is neither a bar chart nor a stacked one. Drawn as ranked ribbons.
